# RelayWorks
RelayWorks is a workflow coordination platform designed for small remote‑work agencies. It provides a clean, structured system for managing clients, assigning tasks to workers, tracking progress, and handling transparent payment flows.
RelayWorks gives admins full control over operations, while clients and workers each get simple, role‑specific dashboards. The platform is built with TypeScript, Node.js, React, and PostgreSQL, making it modular, scalable,


## Current policy and integration work

See [RelayWorks policy and integration contract](docs/relayworks-policy-and-integration.md) for the voluntary 4-4-1 model, PAR target-float and fee parameters, marketplace ceiling, demurrage policy questions, and the boundary between a recorded payout reference and actual settlement. The read-only API endpoint GET /policy exposes the current configured policy defaults; it is not a live currency or RAMS feed.
